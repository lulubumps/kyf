## Descripción

KYF es una pequeña página web estática creada para Katherine y Felipe. Reúne en un solo lugar la información y los enlaces útiles para sus invitados, con una experiencia sencilla y adaptada a dispositivos móviles.

El concepto toma como referencia las páginas de enlaces tipo Linktree, pero con diseño y contenido personalizados para el evento.

## Funcionalidades

- Accesos a la ubicación de la ceremonia y la recepción.
- Enlace para confirmar asistencia por WhatsApp.
- Acceso a una playlist colaborativa en Spotify.
- Alternancia de modo nocturno.
- Diseño adaptable a pantallas móviles y de escritorio.

## Tecnologías

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts (Montserrat)

## Estructura

- **index.html**: contenido principal y enlaces del evento.
- **assets/css/**: estilos y recursos visuales.
- **assets/js/** e **index.js**: interacciones de la página.
- **assets/img/**: imágenes y recursos gráficos.

## Desarrollo local

No requiere compilación ni instalación de dependencias. Clona el repositorio y abre index.html en un navegador. Para una prueba más fiel al sitio publicado, utiliza un servidor estático local.

    git clone https://github.com/lulubumps/kyf.git
    cd kyf

Después, abre index.html en el navegador.
